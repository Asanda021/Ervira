# گزارش اجرای بازسازی ERVIRA

تاریخ: ۱۴۰۵/۰۷/۲۳
شاخه: `design/ervira-studio-rebuild-concept-20261014`

## دامنه اجرا

- صفحه اصلی ریشه به صفحه فارسی راست‌چین و واکنش‌گرا تبدیل شد؛ جست‌وجوی نمونه‌ها، فیلترها، شمارش نتیجه‌ها و وضعیت بدون نتیجه دارد.
- صفحه خدمات با هشت حوزه، خروجی‌ها و گردش‌کار ساخته شد. بخش دفتر فنی عمران صریحاً در حال آماده‌سازی است.
- صفحه درباره‌ما پیش‌نویس امن و `noindex` است و اطلاعات هویتی تأییدنشده در آن درج نشده.
- صفحه مطالعه موردی داشبورد فروش با فایل واقعی XLSX، پیش‌نمایش، فرضیات و محدودیت‌ها افزوده شد.
- پیوندهای عمومی، canonical، متادیتا، sitemap، مسیرهای تماس و ناوبری نمونه‌ها یکپارچه شدند. صفحات نمونه قدیمی نگه داشته شدند.
- اسکریپت‌های QA و گردش‌کار GitHub Actions برای کنترل SEO، پیوندها، نمونه‌فایل‌ها و آزمون مرورگر افزوده/گسترش داده شدند.

## بررسی بسته نمونه‌کارها

- هر ۱۰ فایل Excel از آرشیو پیوست با SHA-256 و اندازه بایت کنترل شد؛ ۱۰ فایل XLSX و ۱۰ پیش‌نمایش PNG در مسیر انتشار آماده‌اند.
- ۳۰ دارایی مستندات (۱۰ DOCX، ۱۰ PDF و ۱۰ WebP) و ۳۰ دارایی ارائه (۱۰ PPTX، ۱۰ PDF و ۱۰ WebP) از بسته‌ها با manifest، اندازه، امضا، CRC و SHA-256 کنترل شدند.
- ۱۰ SVG نمونه و ۱۰ منبع Markdown اتوماسیون در آزمون موجودی تأیید شدند.
- فایل‌های آرشیو منبع تغییر داده نشدند. فایل‌های خروجی واقعی در Pages زیر `public/` قرار دارند.

## آزمون‌های محلی

- `node scripts/validate-seo.mjs` — موفق؛ ۲۳ صفحه اصلی و robots/sitemap.
- `node scripts/validate-public-site-seo.mjs` — موفق؛ ۷۵ مسیر عمومی canonical و سیاست sitemap.
- `node tests/check_public_links.mjs` — موفق؛ ۸۰ صفحه HTML و ۱٬۳۱۱ مقصد/لنگر محلی.
- `ERVIRA_SKIP_BROWSER=1 node tests/qa_ervira_studio.mjs` — موفق؛ مسیرها، فراداده و manifestها.
- `node tests/check_portfolio_phases.mjs` — موفق.
- `python3 -m unittest discover -s tests -p 'test_ervira_*.py' -v` — موفق؛ ۱۴ آزمون.
- `python3 tests/check_sample_downloads.py` پشت سرور HTTP محلی — موفق؛ ۸۰ پاسخ فایل با MIME، اندازه، SHA-256، امضا و CRC.
- `git diff --check` — موفق.

آزمون مرورگر واقعی در محیط محلی به دلیل نبودن مرورگر Playwright قابل اجرا نبود؛ دریافت مرورگر از CDN نیز در محیط محدود ناموفق بود. گردش‌کار GitHub Actions مرورگر Chromium را روی runner نصب و آزمون واکنش‌گرایی را در اندازه‌های ۳۲۰ تا ۱۴۴۰ پیکسل اجرا می‌کند و تصویرهای QA را به‌صورت artifact نگه می‌دارد. نتیجهٔ آن پس از push باید کنترل شود.

## حریم خصوصی، مالکیت و انتشار

- ایمیل `hello@ervira.ir` به‌عنوان کانال فعال استفاده نشد؛ مسیر تماس به فرم توضیح‌داده‌شده محلی می‌رود و هیچ داده‌ای ارسال یا ذخیره نمی‌کند.
- درباره‌ما تا تأیید مالک `noindex` می‌ماند.
- داده‌های نمونه مستقل/آموزشی معرفی شده‌اند؛ محتوای مهندسی یا مشخصات تأییدنشده ساخته نشده است.
- گردش‌کار انتشار Pages همچنان فقط روی شاخه `main` فعال است. این شاخه مستقل است و این گزارش به‌معنای ادغام یا انتشار نیست.
- آزمون محاسبه مجدد Excel در LibreOffice/Office انجام نشد؛ فایل‌ها و خروجی‌های بسته تطبیق باینری و ساختاری شدند.

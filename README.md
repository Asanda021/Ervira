# ERVIRA

**Engineering • Resources • Valuation • Infrastructure • Reporting • Analytics**

ERVIRA is the parent brand for a family of professional engineering software products.

## Website roadmap
- **P1 — Architecture:** corporate shell, store, product hierarchy and future account/licensing routes.
- **P2 — Visual identity:** dark engineering visual language, ERVIRA brand mark, typography and reusable UI tokens.
- **P3 — Home:** product-led homepage with ecosystem, capabilities and contact sections.
- **P4 — Store:** dedicated software store with independent product entries.
- **P5 — Product pages:** dedicated landing pages for StructuralPro, StructureCalc, EstimatePro, OfficePro, SitePro and EngineerAI.

## Current products
- **StructuralPro** — flagship takeoff, estimation and engineering-data platform.
- **StructureCalc** — independent structural calculation/design product.
- **EstimatePro** — project cost estimation.
- **OfficePro** — technical-office workflows.
- **SitePro** — construction-site management.
- **EngineerAI** — engineering AI assistant.

## Stack
Static HTML + CSS + JavaScript, ready for GitHub Pages and custom domain `ervira.ir`.

## Security
Payment secrets, private API keys and licensing secrets must never be stored in frontend code. Future checkout/licensing will use a secure backend.

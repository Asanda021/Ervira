پیش‌نیاز و نحوه اجرا

Python 3.10 یا جدیدتر. دستور را از پوشه‌ای اجرا کنید که فایل ervira_automation.py در آن قرار دارد. بسته آزمایش برای فایل‌های CSV در مسیر data/ آماده است.

۱. پیش‌نمایش بدون تغییر فایل‌ها

python ervira_automation.py rename ./files --prefix project

۲. اجرای صریح پس از بررسی

python ervira_automation.py rename ./files --prefix project --apply
دریافت کد Pythonفایل‌های نمونه

معیار ایمنی و تحویل

از نام‌های مقصد موجود جلوگیری می‌کند و قبل از اعمال، تمام تغییرات را نشان می‌دهد.

رفتار برنامه مطابق ورودی است. قبل از اجرای --apply نسخه پشتیبان فایل‌های خودتان را تهیه کنید.
